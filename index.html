Mis competencias

Conocimientos técnicos, habilidades personales y aprendizaje autónomo.

Técnicas

  • HTML5 y CSS3: maquetación responsive con Flexbox y CSS Grid
  • JavaScript: manipulación del DOM y gestión de eventos
  • Java: programación orientada a objetos (POO/OOP) durante el primer curso
  • SQL con MySQL y PostgreSQL: consultas, JOIN y diseño básico de bases de datos
  • Git y GitHub: control de versiones, commits, ramas y pull requests

Personales

  • Resolución de problemas: análisis y depuración (debugging) de errores mediante hipótesis y pruebas
  • Resiliencia: perseverancia ante errores y cambios, manteniendo el foco en la entrega
  • Adaptabilidad: ajuste de prioridades y enfoque según las necesidades del equipo
  • Trabajo en equipo y colaboración: avances compartidos, revisiones de código (code review) y metodología Scrum

Autodidactas

  • Aprendizaje autónomo: consulto la documentación oficial y practico con proyectos pequeños antes de aplicar una tecnología nueva
  • Práctica continua: resuelvo ejercicios de programación y publico las soluciones en GitHub
  • Pensamiento crítico: comparo soluciones alternativas y justifico cuál conviene según el contexto
Evidencia de técnicas
Aplicadas en los proyectos del ciclo: maquetación responsive con HTML5 y CSS3, DOM y eventos con JavaScript, consultas SQL y control de versiones con Git y GitHub. Código y capturas en el capítulo 03.
Evidencia de personales
En los trabajos en equipo del ciclo compartí avances, acepté revisiones de código y seguí la metodología Scrum. Ante un error lo descomponía y probaba hipótesis hasta localizarlo y mantener la entrega.
